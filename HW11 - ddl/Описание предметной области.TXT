ТЕМА ПРОЕКТА: Домашняя кулинарная книга рецептов с поиском в ней рецептов по ингредиентам

Для организации удобной домашней кулинарии и выполнения таких задач, как:
- пополнение своей "копилки" понравившихся рецептов(быстрое и лёгкое),
- поиск наиболее подходящих в "копилке" рецептов по имеющимся продуктам
предполагается на основе разработанной логической модели
создание хранилища данных КУЛИНАРНЫХ РЕЦЕПТОВ и их ИНГРЕДИЕНТОВ на MS SQL Server
с возможностью работы с ними(ввод/модификация/удаление/поиск/анализ/выбор) 
посредством приложения на MS ACCESS.

Логическая модель отражает планируемую реляционную схему хранилища/базы данных
и представляет собой 12 сущностей(таблиц) в 3NF с атрибутами и связями(отношениями) между ними.
Она выполнена на: https://app.quickdatabasediagrams.com/#/d/tWUFkG
