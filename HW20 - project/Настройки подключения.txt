НАСТРОЙКА ПРОЕКТА ДЛЯ ПРОВЕРКИ

1. Подключиться к SQL Server через SSMS

2. Восстановить базу тестовых данных из бэкапа MyBookForCook.bak
   
3. Выполнить sql-скрипт:
   USE master;
   GO
   CREATE LOGIN user123 WITH PASSWORD = N'123', CHECK_POLICY = OFF;
   GO
   USE MyBookForCook;
   GO
   ALTER USER [owner] WITH LOGIN = user123;
   GO

3. Открыть файл MyBookForCook.accdb (двойным кликом) в MS Access 2016+
   Access должна подключиться к базе автоматически (строка подключения уже есть внутри файла).

4. Если Access запросит логин/пароль — ввести:
   Логин: user123
   Пароль: 123

5. Если сервер называется не .\sql2022, а иначе — 
   в Access: Внешние данные → Диспетчер связанных таблиц → 
   обновить подключение, указав ваше имя сервера.
